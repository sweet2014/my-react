# Weather Update React App

A simple and elegant weather update application built with React.

## Features

- Real-time weather updates
- Search weather by city name
- Clean and responsive UI
- Temperature in Celsius
- Wind speed information
- Weather condition descriptions
- Last update timestamp

## Technologies Used

- React 18.2.0
- Open-Meteo API (free weather API)
- CSS3 with animations

## Getting Started

### Installation

```bash
npm install
```

### Running the Application

```bash
npm start
```

The application will open in your browser at `http://localhost:3000`.

### Building for Production

```bash
npm build
```

## Usage

1. Enter a city name in the search box
2. Click "Get Weather" to fetch the current weather data
3. View temperature, weather conditions, wind speed, and last update time

## API

This application uses the [Open-Meteo API](https://open-meteo.com/), which is free and doesn't require an API key.
